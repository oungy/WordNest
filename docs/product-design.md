# WordNest / 拾词：产品与界面规范

更新：2026-11-04。英文项目名为 WordNest，中文名沿用拾词。此文定义产品行为，不表示对应 Android 功能已实现。

## 已确认方向

- 首先满足个人自用，未来可能开源并推广；仍默认单人本地使用，每位使用者配置自己的 DeepSeek Key。
- Kotlin + Jetpack Compose + Room；普通 LLM 聊天接口，不引入 Agent。未来公开不自动等于需要账号、云同步或业务服务器。
- 视觉参考“不背单词”的克制简洁、大字号、适量背景氛围，使用独立素材和布局。
- 需要每日背词、复习、默认学习分类、自定义词本、词书库、基础 AI 聊天、语境阅读、设置及可升级的数据结构。

## 导航与视觉

设计修订 3 补充：所有可见控件及展开状态必须统一；适量引入 iOS 风格圆角和材质。具体规则见 [统一视觉与交互规范](design-system.md)。上下文、主题、语言和发音选择器全部采用统一浮层，增加减少透明效果设置。

底部导航：今日／词本／阅读／AI。设置入口放在今日、词本顶部以及 AI 页的服务配置入口。

- 今日：新学与待复习数量、继续学习、复习入口、今日阅读。初版练习预览固定为 3 个示例词。
- 词本：学习记录 → 我的词本 → 词书库；层级清楚，不将所有分类排成一排筛选按钮。
- 阅读：连续英文排版，默认收起翻译；词义与 AI 面板就近展开。
- AI：独立普通聊天入口，也允许从单词、文章或词本带入上下文。
- 浅色、深色和跟随系统；低饱和强调色；可调阅读字号、目标词高亮与首页氛围。
- 原生版主要触控区至少 48dp，文字使用 sp；支持大字号、系统返回、窄屏、减少动画、正常文本至少 4.5:1 对比度。

## 词本的三种概念

### 系统学习分类：入口固定，不可删除

生词：用户主动收藏的词，可取消收藏。错词：存在错误或遗忘记录的词；历史与“当前待巩固”筛选分开。已学：至少完成一次学习；已掌握：达到明确复习条件，不能由 LLM 或一次学习直接判定。

这些是数据筛选视图，不是四套复制出来的词条。它们允许重叠，例如一个词同时属于已学和错词。删除自定义词本不影响这些视图。

### 自定义词本：用户管理的集合

- 创建、重命名、删除、选择单词加入；同一词可在多个词本中。
- 名称去首尾空格，规范化后 1–32 字符；不允许规范化后同名。名称仅用于显示，以稳定 ID 建立关系。
- 从本地搜索、多选或单词详情加入；重复加入不重复计数。单词详情可以管理多个自定义词本归属。
- 从词本移除仅删除关联，不删除词条、其他词本关联或学习历史。
- 删除词本前明确说明影响范围并确认，不能级联删除学习记录。
- 空词本展示添加入口；后续可增加排序、说明和封面色，不影响身份标识。
- AI 可提出分组、标签、词本名称建议，应用前展示预览；程序校验输出，不让模型直接写学习状态。

### 词书库：有来源、版本和内容范围的词汇包

覆盖初中、高中、CET-4、CET-6、IELTS 备考分类。词书是学习材料，不是用户收藏本。词书更新与 App 更新分离。

- 每本展示名称、来源机构或编者、依据版本、内容包版本、实际词条数、释义／音频来源及分发许可。
- “依据官方大纲整理”与“官方出版／授权”必须分别标注；未获授权不得暗示官方背书。
- CET 以考试机构大纲为依据候选，初高中以课标为依据候选；具体教材版词本需另标出版社、年级、册次和版次。
- IELTS 使用核实来源的备考词表；当前没有确认可直接内置、可分发的官方全量词书，不作该承诺。
- 更换学习词书保留同一词条的学习历史；书内进度据关联词条计算。
- 移除词书下载内容与删除个人学习记录是不同操作；正在被个人词本或记录引用的词条应保留必要内容。
- 更新内容包使用稳定词条 ID，不能依据位置或名称重建进度。释义改正不能覆盖用户笔记。
- 允许导入自有词表，分享和公开分发前仍需有明确来源范围。

## 当前在学词书与每日计划

2026-11-04 补充确认：用户可以选择一本或多本词书作为当前在学词书，每日新词从这些词书中挑选。下载或收藏词书不自动将其加入学习计划。

界面需提供在学词书管理入口，支持多选、查看每本进度及保存选择；今日页展示当前在学词书摘要和修改入口。选择面板沿用统一视觉规范，包括选中、禁用、空态、取消及焦点返回。

以下为首版建议默认规则，后续可按实际体验调整：

- 每日新词量是所有在学词书的合计，例如选择两本、每日 20 词，合计仍为 20 词。
- 多本词书默认轮流取词、尽量均衡分配；书内先按内容包顺序选择未学词。某本剩余词不足时由其他在学词书补足；全部不足则展示实际数量。
- 同一个稳定词条 ID 在当日计划中只出现一次，共享学习状态，并计入各所属词书的进度；不能只按拼写合并不同词义的条目。
- 新词来源与复习队列分开：新词取自当前在学词书，到期复习依据已有学习记录。取消在学不删除进度，已学词仍按原计划复习。
- 当日计划生成后持久保存，退出、重启或重复打开页面不重新抽词。更改在学词书或每日数量默认从下一天生效；首次生成计划使用当前设置。
- 没有选择在学词书时，显示选书入口，不自动从全部词库取新词；已有复习仍可进行。词书新词学完时提示完成，并保留复习入口。

此节定义原生版目标，当前 HTML 预览尚未实现多词书学习计划。

## 设置范围

| 分组 | 正式版范围 | 第二版预览 |
| --- | --- | --- |
| 通用／学习 | 每日新词量、默认发音、自动发音、提醒开关与时间 | 新词量、发音选项；不调度提醒或播放音频 |
| 主题／阅读 | 系统／浅／深主题、强调色、字号、背景氛围、目标词高亮 | 实时主题、三种强调色、字号、氛围、高亮 |
| 语言 | 系统／简体中文／英文界面，AI 讲解语言独立 | 设置、词本和导航可切换；旧学习样例未完整翻译 |
| AI | Key、模型、连接验证、回答偏好、上下文范围、历史管理 | 配置与聊天入口；禁用 Key 输入，不联网 |
| 数据 | 本地词表导入、学习备份、恢复预览、缓存管理 | 行为说明，无真实导入导出 |
| 关于 | 应用版本、更新日志、检查更新、词书版本、许可证与项目链接 | 设计稿版本与更新说明，无线上仓库 |

设置在原生版中使用本地持久化。界面语言不自动翻译用户词本名称、原文文章或词典内容。恢复默认设置不删除学习数据。

## DeepSeek 是首个可用版本的核心功能

原型的固定讲解示例不算 API 接入完成。验收必须包含真实网络调用，而不是只展示聊天界面。

- 用户在原生 App 填写自己的 Key；通过 Android Keystore 管理的密钥加密其本地存储。
- 默认 DeepSeek 官方地址，通过模型列表接口获取可用模型，避免在 UI 固定过时的型号。
- 普通多轮聊天支持流式输出、停止、失败重试、新建会话和本地历史。
- 用户明确选择自由聊天、当前单词、今日词汇、自定义词本或当前文章作为上下文；不自动发送全库。
- 生成阅读需展示选中的目标词、主题与模式；保存生成结果、覆盖检查与模型信息。
- 服务不可用、无 Key、鉴权失败、余额或限流错误、断网、取消分别处理。API 失败不能影响背词记录。
- 不记录 Key 到日志；学习备份和公开仓库排除 Key。API 使用费用由各自 Key 对应账户承担。
- 清晰区分词典原文、用户笔记与 AI 生成说明；模型不直接修改词典事实或答题记录。

## 当前完成情况

已完成三版可点击设计预览；第二版建立词本与设置流程，第三版统一选择浮层和控件材质。可以创建／改名／删除自定义词本、多选添加和移除示例词、查看固定分类、调整主题等设置。状态只在当前预览交互中有效。

已创建 Android 初始工程，原生内容仅为欢迎页，并配置调试 APK 构建流程。没有接入真实 DeepSeek，没有下载或内置完整词书，没有完成持久化、复习调度和升级程序。不能将设计预览或工程初始化版本等同于完整可用 App。

下一阶段首个原生可用版本必须一起交付：本地词库与词本、学习记录、设置持久化、实际 DeepSeek 普通聊天和阅读生成、数据备份；然后再扩大词书覆盖与发布范围。
